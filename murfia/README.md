# 🐾 МУР-ФИЯ: Кошачьи Разборки

Онлайн-«Мафия» в реальном времени для 6–12 котов. Город — Мурград, мафия — Чёрные Коты,
днём коты спорят и голосуют лапками, ночью роли просыпаются по очереди.

**Стек:** React 18 + TypeScript + Tailwind CSS 3 + Framer Motion + Zustand · Node.js + Express + Socket.IO ·
SQLite (better-sqlite3) · Web Audio API (звуки без аудиофайлов).

---

## 🚀 Быстрый старт

Нужен Node.js 20+.

```bash
npm install
npm run dev          # сервер :3001 + клиент Vite :5173 → открой http://localhost:5173
```

Продакшен (сервер сам раздаёт собранный клиент):

```bash
npm run build        # проверка типов + сборка клиента в dist/
npm start            # http://localhost:3001
```

Проверки без сети и без браузера:

```bash
npm test             # симуляция полных партий игрового ядра (см. «Тесты»)
npm run typecheck    # tsc --noEmit по клиенту и общим типам
```

Одному играть можно сразу: в комнате жми «🤖 + ИИ-кот» или просто «Начать партию» —
недостающих до 6 игроков заменят боты. Чтобы позвать друзей, дай им код комнаты (5 символов).

Переменные окружения (все необязательные):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3001` | порт сервера |
| `MURFIA_DB` | `data/murfia.db` | файл SQLite |
| `MURFIA_SPEED` | `1` | ускорение всех таймеров (для тестов, например `50`) |
| `VITE_SERVER_URL` | тот же origin | адрес сервера, если клиент и сервер на разных хостах |

> Если `better-sqlite3` не собрался (нет компилятора/prebuild), сервер **не падает**: он честно пишет
> предупреждение и хранит профили в памяти до перезапуска. Пакет объявлен как `optionalDependencies`.

### Главные архитектурные решения (и почему)

1. **Ядро не знает про сеть.** `game.js` общается с клиентами через «хаб» (`hub.emit(socketId, event, …)`).
   Поэтому всю логику можно гонять в тестах без Socket.IO, а `index.js` остаётся тонким.
2. **Сервер авторитарен, клиент — «глупый».** Клиент получает не «весь мир», а **персональное
   представление** (`Room.view(playerId)`): чужие роли не уходят в сеть вообще — их нельзя подсмотреть
   в DevTools. Мафия видит банду, мёртвые — роли погибших, после игры открыто всё.
3. **Реконнект по токену.** При первом входе сервер выдаёт секретный токен (localStorage). После обрыва
   или перезагрузки страницы клиент логинится тем же токеном и сразу попадает в свою комнату:
   приходят `chat:history` и `game:state`.
4. **Автопилот.** Не вернулся за 20 с во время партии — за него играет ИИ (ходы, голос); вернулся —
   управление снова у него. Вышел из партии насовсем — его место занимает бот, партия не рассыпается.
5. **Не выдаём состав стола.** Если роль мертва или её нет, ночной шаг всё равно «проходит» (пауза 4 с) —
   по скорости ночи нельзя понять, кто жив.
6. **Один источник правды по времени.** Сервер шлёт `phaseEndsAt` + `serverNow`; клиент считает поправку
   часов, поэтому таймеры у всех совпадают.
7. **JS на сервере + JSDoc, TS на клиенте.** Сервер запускается командой `node` без сборки; контракт
   протокола при этом строго типизирован в `shared/types.ts` и проверяется на клиенте.

## 🎮 Правила

### Роли

| Роль | Команда | Способность |
|---|---|---|
| 🐈 Мирный кот | город | спит, днём ищет мафию и голосует |
| 🐈‍⬛ Чёрный Кот | мафия | ночью банда выбирает жертву; свой чат |
| 😼 Дон Кото | мафия | главарь; при ничьей в банде решает он; детектив видит его «мирным» |
| 🩺 Кот-Доктор | город | лечит одного за ночь (можно себя), но не одного и того же две ночи подряд |
| 🕵️ Кот-Детектив | город | проверяет одного за ночь: «мирный» / «из банды» (Дон и Маньяк — «мирные») |
| 💘 Кот-Купидон | город | в 1-ю ночь связывает двух котов: умирает один — второй умирает от тоски |
| 🧙 Кот-Маньяк | сам за себя | убивает каждую ночь; побеждает, если останется один |

### Состав на n игроков (`buildRoleList` в `shared/constants.js`)

| Игроков | Мафия (с Доном) | Доктор | Детектив | Купидон | Маньяк | Мирные |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 6  | 1 | 1 | 1 | – | – | 3 |
| 7  | 1 | 1 | 1 | – | – | 4 |
| 8  | 1 | 1 | 1 | 1 | – | 4 |
| 9  | 2 | 1 | 1 | 1 | 1 | 3 |
| 10 | 2 | 1 | 1 | 1 | 1 | 4 |
| 11 | 3 | 1 | 1 | 1 | 1 | 4 |
| 12 | 3 | 1 | 1 | 1 | 1 | 5 |

Баланс — первая настройка «на глаз»; его стоит подкрутить после живых партий (см. «Улучшения»).

### Цикл партии

| Фаза | Длительность | Что происходит |
|---|---|---|
| 🎴 Раздача | 7 с | каждый видит свою роль |
| 🌙 Ночь | шаги по 15–25 с | по очереди: Купидон (только 1-я ночь) → Банда → Маньяк → Доктор → Детектив. Шаг заканчивается досрочно, когда все действующие сделали выбор |
| 🌅 Утро | 7 с | рассказ ведущего: кто погиб (роль раскрывается), кого спас доктор |
| ☀️ День | 120 с | чат; если большинство живых людей нажало «Готов к голосованию» — голосование начинается раньше |
| 🐾 Голосование | 30 с | клик по коту — над ним появляется лапка; голос можно менять; можно воздержаться |
| ⚖️ Изгнание | 5 с | единственный лидер по голосам изгнан, роль раскрыта; при ничьей — никого |

Мафия выбирает жертву голосованием: большинство; при равенстве решает Дон Кото. Мафия не может выбрать своего.
Если жертву мафии и/или маньяка лечил доктор — она выживает.

### Победа

- **Город** — не осталось ни мафии, ни маньяка.
- **Мафия** — мафиози не меньше, чем всех остальных живых.
- **Маньяк** — остался один.

### Чат

- день — все живые; ночью — только банда (канал «банда»); мёртвые общаются в канале призраков;
- системные сообщения ведущего, личные подсказки ролям (результат проверки детектива, любовь);
- каждая реплика всплывает **пузырём над головой кота** на столе.

### Профиль

Аватар — одна из 8 карточек пород (`public/cats/`: русская голубая, мэйн-кун, сфинкс, абиссинская, девон-рекс, экзот, бенгальская, рэгдолл), имя, игры/победы, 8 достижений («Девять жизней» — спаси кота доктором, и т. д.).

## 📡 Протокол Socket.IO (полные типы — `shared/types.ts`)

**Клиент → сервер** (все с `ack({ ok, error? })`): `profile:login`, `profile:update`, `rooms:list`,
`room:create`, `room:join`, `room:leave`, `room:addBot`, `room:kickBot`, `room:start`, `room:rematch`,
`chat:send`, `vote:cast`, `night:action`, `day:skip`.

**Сервер → клиент:** `game:state` (персональное состояние), `chat:message`, `chat:history`,
`game:event` (фаза / утро / изгнание / проверка детектива / любовь / конец игры), `rooms:list`,
`profile:update`, `room:closed`.

Любая ошибка игрока (опоздал с ходом, недопустимая цель, не твоя фаза) возвращается в `ack` понятным
текстом в стиле игры и **ничего не роняет** на сервере; таймеры обёрнуты в `guard`.

## 🤖 ИИ-коты

Боты ходят через те же методы комнаты, что и люди (`nightAction` / `vote` / `chat`), поэтому не могут
«читерить». Логика (`server/bots.js`) — случайность + простые стратегии:

- **Мафия** согласует жертву с бандой (75% присоединяется к уже выбранной), пишет в ночной чат, не бьёт и не голосует против своих.
- **Детектив** запоминает найденных мафиози и потом голосует за них. **Доктор** лечит случайного (иногда себя). **Купидон** и **Маньяк** выбирают случайно.
- **Голосование:** рулетка по «подозрительности» — растёт у тех, кто голосовал за изгнанного мирного, падает у голосовавших за изгнанную мафию; плюс эффект толпы; 6% воздерживаются.
- **Чат:** обвинения, оправдания и «мяу» в случайные моменты дня.

## 🧪 Тесты

`npm test` → `server/test/simulate.mjs`: 36+ полных партий (6–12 игроков, 1–3 скриптовых «человека» + боты) на ускорении ×300. Проверяется:

- каждая партия доходит до конца и победитель определён по правилам;
- набор ролей соответствует таблице;
- **нет утечки скрытой информации** (чужие роли и голоса мафии не попадают в `view()` лишним игрокам);
- детектив видит Дона и Маньяка «мирными»; любовь взаимна; статистика людей записана;
- точечные правила: доктор спасает жертву, мафия не бьёт своих, одно ночное действие за ночь.

## 🔧 Идеи для развития

- Ввести ранги/ELO и серверный рейтинг; публичная таблица лидеров.
- Хозяин настраивает состав ролей и длительности фаз; «закрытые» комнаты с паролем.
- Голосовой чат (WebRTC) и эмодзи-реакции на реплики.
- Сильнее ИИ: логика «доверия» между ботами, блеф мафии-ботов, «клейм» ролей.
- Масштабирование: хранить комнаты в Redis + `@socket.io/redis-adapter`, sticky sessions.
- Анти-спам и жалобы, модерация имён; настоящая авторизация (OAuth) вместо токена в localStorage.
- Автотесты клиента (Playwright) и сокет-слоя (e2e с настоящим `socket.io-client`).
- Новые роли: Сыщик-стажёр, Адвокат, Журналист; альтернативные механики голосования.
